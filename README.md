# Rock Paper Scissors

## Description
This is a simple Rock Paper Scissors game built with JavaScript.

## Overview
A console-based game where the player competes against the computer.
The project focuses on basic JavaScript logic, functions, conditionals, and loops.

## Tech Stack
* JavaScript

## Usage
Run the script in the browser console or with Node.js to play the game.

## Notes
This project was built as part of the Foundations Course.
The game currently runs entirely in the console.
